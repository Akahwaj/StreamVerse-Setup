# StreamVerse Setup Web

A lightweight, installable web companion for StreamVerse. It provides a curated 15-item Stremio add-on list, custom manifest handoff, private device-local Live TV URL storage, QR sharing, and direct links to Stremio and Nuvio community resources.

## Privacy

- No account or sign-in is required.
- No credentials, debrid tokens, or private manifests are bundled.
- Live TV URLs are stored only in the current browser's local storage.
- QR codes are rendered in the browser; the encoded link is not submitted to the website.

## Hosting

The deployable static site is in `dist/`.
